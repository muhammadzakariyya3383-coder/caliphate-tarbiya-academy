Welcome

Welcome to the Caliphate Tarbiya Academy Academic Management System. Teachers can prepare lesson documents, generate assessment questions, submit assessments to the appropriate HOD and follow the approval workflow.

School Levels Supported

  • Nursery 1–3
  • Basic 1–6
  • JSS 1–3
  • SS 1–3

Assessment Workflow

Teacher → HOD → Examination Officer → Finalized → Word Document

Select the class and subject, enter the topic, then use Automatic Generation or write everything manually.

CA & Examination

The system automatically sends the assessment to the HOD assigned to the selected subject. The teacher does not manually select an HOD.

The Assistant changes its question style according to Nursery, Basic, JSS or SS. For SS classes it produces original WAEC/NECO-style questions.
